## Ключевая особенность раздела 1

Все опубликованные численные результаты (Accuracy, F1, AUC и др.), упомянутые в таблицах сравнения архитектур, **снабжены явной ссылкой на первоисточник** — конкретную рецензируемую работу с указанием датасета и постановки задачи (binary/multiclass). Прямое количественное сравнение между источниками **не производится** в силу зафиксированных методологических ограничений (различие препроцессинга, разделений и метрик); сравнение моделей в равных условиях выполняется в собственных экспериментах Этапа 4.

## Решения, зафиксированные на этапе

- **Основная модель:** CNN-LSTM (обоснование по 4 независимым обзорным/первичным источникам).
- **Альтернативы:** BiLSTM, Transformer-encoder.
- **Контрольные semi-supervised:** AE, VAE.
- **Классические baselines:** LR, RF, XGBoost, IF, OCSVM, MLP, 1D-CNN, LSTM, GRU, TCN.
- **Окно:** W=32, шаг S=W/4 (75% перекрытие).
- **Балансировка:** focal loss (γ=2.0) + class re-weighting; SMOTE только для классических.
- **Drift-monitoring:** PSI (порог 0.25), KL, MMD (95-перцентиль bootstrap).
- **Cross-evaluation:** UNSW-NB15 → CICIDS2017 на 14 общих признаках.
- **Эксперименты:** E1–E6 + E4' с фиксированными критериями принятия гипотез.
